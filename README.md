# Shizenryu Student Hub

The digital home for students of Shizenryu Karate — *The Natural Way of Karate*.

**Live site:** deployed automatically to Netlify from the `site/` folder on every push to `main`.

## What's here

| Page | Purpose |
|---|---|
| `site/index.html` | Landing page — maxim of the day, links to everything |
| `site/quiz.html` | Dojo Quiz — Japanese terminology by belt level, plus Kumite 1–12 sequence training |
| `site/flashcards.html` | Philosophy flashcards — the Maxims, Zen & Karate, Tui Shou, and more |
| `site/docs/` | Printable PDFs: grade study guides, philosophy study guide, belt passport |
| `site/assets/data.js` | All quiz/flashcard content — edit here to add material |

## Working on this repo

No build step — it's plain HTML/CSS/JS. Open any page straight from disk to preview.

Start with **CLAUDE.md**: it documents the structure, data schemas, design system,
content rules (all martial content comes from the official syllabus and source papers),
and the verification checklist to run before committing.
